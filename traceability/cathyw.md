## Generator coverage

The properties include extensionless filenames, ignored-directory names used as ordinary filenames, arbitrary unfamiliar roots, exact ignored directory segments at multiple depths, duplicates, and unchanged session-reference inputs. Explicit 29/30/31/50 group fixtures and 19/20/21/25 subgroup fixtures guarantee boundary coverage instead of relying on large array limits. The usual properties run 200 generated cases. The R1 boundary properties run 30 cases per group count, checking all four subgroup counts each time, and R3/R7 boundary properties run 50 cases per group count.
